# Chatbot de Vendinha com IA 🛒

Um protótipo minimalista de chatbot para mercadinho que responde perguntas em linguagem natural utilizando dados reais de estoque injetados dinamicamente via contexto no Gemini.

## Pré-requisitos

* Node.js instalado (versão 18+ recomendada)
* Uma chave de API do Google Gemini (`GEMINI_API_KEY`)

## Como Rodar Localmente




1. Clone este repositório:
   ```bash
   git clone [https://github.com/dsbrogio/chatbot-vendinha.git](https://github.com/dsbrogio/chatbot-vendinha.git)
Crie um arquivo .env na raiz do chatbot e dentro dele insira a linha: GEMINI_API_KEY=chave de API salve.
cd chatbot-vendinha
npm start
acesse: http://localhost:3000
